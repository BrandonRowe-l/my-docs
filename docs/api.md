# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：按 id 返回单篇文档的标题与正文摘要。

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "summary": "修改 Markdown 文件并推送后自动更新网站"
}
```

## 创建文档条目

- 请求方法：POST
- 请求路径：/api/docs
- 功能：新增一条文档条目。

### 请求示例

```json
{
  "title": "新文档标题",
  "content": "文档正文内容"
}
```

### 返回示例

```json
{
  "id": 2,
  "title": "新文档标题",
  "created": true
}
```

## 错误码说明

| 状态码 | 含义 | 说明 |
| --- | --- | --- |
| 200 | OK | 请求成功 |
| 404 | Not Found | 指定 id 的文档不存在 |
| 400 | Bad Request | 请求参数缺失或格式错误 |

## 文档编写说明

本页虽然是示例接口，但遵循了真实 API 文档的常用写法：先说明请求方法与路径，再给出请求/返回示例，最后用表格汇总错误码。在实际项目中，接口文档应与代码同步维护，建议在持续集成流程中对文档示例做格式校验，避免文档与实现脱节。更多本项目背景请查看[关于本项目](about.md)，本地调试方法见[使用指南](guide.md)。
